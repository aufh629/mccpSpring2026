1. Introduction

Problem: KRR has excellent theoretical properties but requires a-priori regularization parameter selection, which is infeasible in practice.

Existing Methods: Hold-out (HO), Discrepancy Principle (DP), and Lepskii-type Principle (LP) all have limitations - HO wastes samples, DP is sub-optimal, LP requires expensive pairwise comparisons and achieves only near-optimal rates.

Main Contribution: Proposes ASUS (Adaptive Selection with Uniform Subdivision) - an early-stopping type parameter selection strategy that removes recurrent pairwise comparisons and achieves optimal learning rates.
→ Section 2 → Section 3

KRR Definition

Kernel Ridge Regression: f_{D,λ} = argmin_{f∈H_K} {1/|D| Σ(f(x)-y)² + λ||f||²_K}

Computational complexity: O(|D|²) storage, O(|D|³) training. Theoretical assessments show KRR is an excellent learner under proper assumptions.
→ Assumptions → Optimal Rates

Three Standard Assumptions

Assumption 1 (Boundedness): Bernstein noise condition for bounded/Gaussian/sub-Gaussian noise.

Assumption 2 (Regularity): f_ρ = L_K^r h_ρ for some h_ρ ∈ L²_{ρ_X}, where r > 0 describes regularity.

Assumption 3 (Effective Dimension): N(λ) = Tr((λI+L_K)⁻¹L_K) ≤ C₀λ⁻ˢ for some s ∈ (0,1].
→ Lemma → Section 3

Optimal Learning Rates (Lemma)

Under Assumptions 1-3, with optimal parameter λ* = c₀|D|^(-1/(2r+s)):

||f_{D,λ*} - f_ρ||_ρ ≤ C̃|D|^(-r/(2r+s)) log(2/δ)
||f_{D,λ*} - f_ρ||_K ≤ C̃|D|^(-(r-1/2)/(2r+s)) log(2/δ)

Problem: λ* depends on unknown r and s, making it impractical.
→ LP Method → Section 3

Lepskii Principle (LP)

LP uses logarithmic subdivision: λ_k = q^k for q ∈ (0,1).

Stopping Rule: λ_LP = max{λ_k: ||(L_{K,D}+λ_k)^(1/2)(f_{D,λ_k'} - f_{D,λ_k})||_K ≤ C_LP W_{D,λ_k} log³(8/δ), k' = k+1,...,K_q}

Limitations: Requires recurrent pairwise comparisons (expensive), achieves only near-optimal rates with double logarithmic factor.
→ Section 3 ← Introduction

Spectral Property (Proposition)

Key Insight: Uniform subdivision (λ_k = 1/(bk)) better captures spectral properties than logarithmic subdivision.

For uniform subdivision: ||(L_{K,D}+λ_k I)^(1/2)(f_{D,λ_k} - f_{D,λ_{k+1}})||_K ≤ C̄₁bλ_k(W_{D,λ_k} + λ_k^r) log²(8/δ)

This enables optimal rates through delicate subdivision.
→ ASUS ← Section 2

ASUS Algorithm

Adaptive Selection with Uniform Subdivision:

Parameter set: Λ^uni_b = {λ_k = 1/(bk) : 0 ≤ k ≤ K*}

Early-stopping rule: Find first k (from K* downward) such that ||(L_{K,D}+λ_{k-1}I)^(1/2)(f_{λ_k,D} - f_{λ_{k-1},D})||_K ≥ C_{US}W_{D,λ_k} log²(8/δ)

Advantages: No recurrent pairwise comparisons needed, achieves optimal rates.
→ Theorem ← Optimal Rates

Main Theorem (ASUS Optimality)

Under Assumptions 1-3, with confidence 1-δ:

||f_{D,λ̂_uni} - f_ρ||_ρ ≤ C₁|D|^(-r/(2r+s)) log⁴(8/δ)
||f_{D,λ̂_uni} - f_ρ||_K ≤ C₁|D|^(-(r-1/2)/(2r+s)) log⁴(8/δ)

Achieves optimal learning rates! Better than LP, DP, and comparable to HO.
→ Proofs ← Introduction
