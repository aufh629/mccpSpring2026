1. Introduction

This section establishes the research problem and motivation. It introduces Kernel Ridge Regression (KRR) as a widely used regression method with strong theoretical guarantees, but highlights the critical limitation that existing theoretical results depend on a-priori parameter selection, which is impractical in real applications.

The section reviews three existing approaches: Hold-out (HO), Discrepancy Principle (DP), and Lepskii-type Principle (LP), discussing their limitations. The main contribution is proposing ASUS (Adaptive Selection with Uniform Subdivision) - an early-stopping type parameter selection strategy.

2. Kernel Ridge Regression and Parameter Selection

Assumption 1: Boundedness
Label: Assumption:boundedness
Assume ∫_Y y²dρ < ∞ and Bernstein noise condition: ∫_Y (e^(|y-f_ρ(x)|/M) - |y-f_ρ(x)|/M - 1) dρ(y|x) ≤ γ²/(2M²) for all x ∈ X, where M and γ are positive constants. This is the well-known Bernstein noise assumption, satisfied for bounded, Gaussian and sub-Gaussian noise.
Assumption 2: Regularity
Label: Assumption:regularity
For r > 0, assume f_ρ = L_K^r h_ρ for some h_ρ ∈ L²_{ρ_X}, where L_K^r denotes the r-th power of L_K: L²_{ρ_X} → L²_{ρ_X} as a compact and positive operator. This describes the regularity of the regression function f_ρ, where larger index r implies better regularity.
Assumption 3: Effective Dimension
Label: Assumption:effective dimension
There exists some s ∈ (0,1] such that N(λ) = Tr((λI+L_K)⁻¹L_K) ≤ C₀λ⁻ˢ, where C₀ ≥ 1 is a constant independent of λ. This is the capacity assumption measured by the effective dimension.
Lemma: Optimal Learning Rates for KRR
Label: Lemma:Optimal-KRR
Let δ ∈ (0,1). Under Assumptions 1-3 with 0 < s ≤ 1 and 1/2 ≤ r ≤ 1, if λ* = c₀|D|^(-1/(2r+s)), then with confidence at least 1-δ, there holds: ||f_{D,λ*} - f_ρ||_ρ ≤ C̃|D|^(-r/(2r+s)) log(2/δ) and ||f_{D,λ*} - f_ρ||_K ≤ C̃|D|^(-(r-1/2)/(2r+s)) log(2/δ), where c₀, C̃ are constants independent of |D|, λ, δ.
Lemma: Optimal Learning Rates for KRR with LP
Label: Lemma:Optimal-KRR-LP1
Let δ ∈ (0,1). If Assumptions 1-3 hold with 0 < s ≤ 1 and 1/2 ≤ r ≤ 1, then with confidence at least 1-δ, there holds: ||f_{D,λ_LP} - f_ρ||_ρ ≤ C̃|D|^(-r/(2r+s)) (log log |D|) log(2/δ) and ||f_{D,λ_LP} - f_ρ||_K ≤ C̃|D|^(-(r-1/2)/(2r+s)) (log log |D|) log(2/δ), where C̃ is a constant independent of |D|, δ. This shows that LP achieves near-optimal rates with a double logarithmic factor.

3. Adaptive Parameter Selection for KRR

Proposition: Spectral Property of KRR
Label: Prop:crucial-stopping-KRR
If Assumption 1 (Boundedness) and Assumption 2 (Regularity) hold with 1/2 ≤ r ≤ 1, then for any λ, λ' satisfying C₁* max{U_{D,λ,δ}, U_{D,λ',δ}} ≤ 1/4, with confidence 1-δ, there holds: ||(L_{K,D}+λI)^(-1/2)(f_{D,λ} - f_{D,λ'})||_K ≤ 2^(r+1/2) ||h_ρ||_ρ (|λ'-λ|/λ) λ^r + 16√2(κM+γ)(|λ'-λ|/λ') W_{D,λ} log²(8/δ). This proposition quantifies the role of subdivision via the terms |λ'-λ|/λ and |λ'-λ|/λ', showing that uniform subdivision better captures spectral properties than logarithmic subdivision.
Definition: Adaptive Selection with Uniform Subdivision (ASUS)
Label: Definition:adaptive-uni
For b ∈ ℕ, λ_k = 1/(bk) and δ ∈ (0,1), define K* = K_{δ,D,b} = min_{0≤k≤|D|/b} {C₁* U_{D,λ_k,δ} ≤ 1/4} and Λ^uni_b = {λ_k = 1/(bk) : 0 ≤ k ≤ K*}. For λ_k ∈ Λ^uni_b with k = K*, K*-1, ..., 1, define k̂_uni to be the first k satisfying: ||(L_{K,D}+λ_{k-1}I)^(1/2)(f_{λ_k,D} - f_{λ_{k-1},D})||_K ≥ C_{US} W_{D,λ_k} log²(8/δ), where C_{US} = 32√2b(κM+γ). If no such k exists, define k̂_uni = K*. Write λ̂_uni = λ_{k̂_uni}. ASUS is an early-stopping type parameter selection strategy that removes recurrent pairwise comparisons.
Theorem: Optimality of ASUS
Label: Theorem:ASUS
Let δ ∈ (0,1). If Assumptions 1-3 hold with 0 < s ≤ 1 and 1/2 ≤ r ≤ 1, then with confidence at least 1-δ, there holds: ||f_{D,λ̂_uni} - f_ρ||_ρ ≤ C₁|D|^(-r/(2r+s)) log⁴(8/δ) and ||f_{D,λ̂_uni} - f_ρ||_K ≤ C₁|D|^(-(r-1/2)/(2r+s)) log⁴(8/δ), where C₁ is a constant independent of |D|, λ, δ. This theorem shows that KRR equipped with ASUS achieves optimal learning rates, demonstrating the feasibility and optimality of ASUS.

4. Proofs

This section provides rigorous mathematical proofs of all main results. It uses the integral operator approach, establishing key lemmas for bounding operator differences, and then proves the main theorem on ASUS optimality through careful analysis of the spectral properties and uniform subdivision.

Lemma: Bounds on Operator Quantities
Label: Lemma:Q
Let D be a sample drawn independently according to ρ and 0 < δ < 1. Under Assumption 1 (Boundedness), if C₁* U_{D,λ,δ} ≤ 1/4, then with confidence at least 1-δ, there simultaneously holds bounds on S_{D,λ}, Q_{D,λ} ≤ √2, P_{D,λ}, and the empirical effective dimension N_D(λ) in terms of the population effective dimension N(λ). This lemma provides tight bounds on key operator quantities that play a crucial role in the proofs.
